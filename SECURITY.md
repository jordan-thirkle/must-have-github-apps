# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability in this repository.

Use GitHub's private vulnerability reporting feature when available. If it is unavailable, contact the repository owner privately through the email listed on the GitHub profile and include:

- a clear description of the issue;
- affected files, workflows, or versions;
- reproduction steps or proof of concept;
- impact and suggested mitigation.

Please avoid including secrets or personal data in reports. I will acknowledge valid reports and coordinate a fix or disclosure timeline where appropriate.

## Scope

This policy covers the repository's code, documentation, automation, and configuration. It does not make security claims about any third-party GitHub App listed in the directory. Report issues in those products to their respective maintainers.
